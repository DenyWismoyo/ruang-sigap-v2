# Paket Dokumen & Data Master BLUD Solo Technopark (STP)

Folder ini berisi seluruh data master, template impor CSV, daftar akun pengguna, dan panduan operasional SIGAP E-Office untuk lingkungan **UPTD Kawasan Sains dan Teknologi Solo Technopark (STP)** dalam format **Markdown (.md)**, **PDF Siap Cetak (.pdf)**, dan **CSV (.csv)**.

---

## 📁 Daftar Berkas dalam Folder Ini:

### 1. Dokumen Panduan Pengguna
* **[PANDUAN_RINGKAS_PENGGUNA.pdf](./PANDUAN_RINGKAS_PENGGUNA.pdf)** (Format PDF Siap Cetak & Sebar)
* **[PANDUAN_RINGKAS_PENGGUNA.md](./PANDUAN_RINGKAS_PENGGUNA.md)** (Format Teks Markdown)
  * *Isi:* Panduan alur kerja inti bagi pegawai: Cara Login di [https://sgp.omnifit.cloud](https://sgp.omnifit.cloud), Upload Surat Masuk oleh TU, Disposisi Pimpinan, Ruang Kerja Digital, dan Laporan Kinerja.

### 2. Daftar Akun Pengguna Pegawai
* **[DAFTAR_AKUN_PEGAWAI_BLUD_STP.pdf](./DAFTAR_AKUN_PEGAWAI_BLUD_STP.pdf)** (Format Tabel PDF Siap Cetak)
* **[DAFTAR_AKUN_PEGAWAI_BLUD_STP.md](./DAFTAR_AKUN_PEGAWAI_BLUD_STP.md)** (Format Teks Markdown)
  * *Isi:* Tabel daftar lengkap 45 akun pegawai BLUD STP Tahun 2026 beserta NIK (Username), Password Default (`StpUser2026!`), dan jabatan.

### 3. Berkas Impor Sistem (CSV)
* **[users_blud_stp.csv](./users_blud_stp.csv)**
  * Template CSV Akun Pengguna BLUD STP yang siap diimpor massal ke menu Manajemen Pengguna.
* **[jabatan_blud_stp.csv](./jabatan_blud_stp.csv)**
  * Template CSV Master Jabatan BLUD STP lengkap dengan relasi `namaAtasan` otomatis dan penanda `klasterStruktur` = `blud`.
