# Paket Dokumen & Data Master BLUD Solo Technopark (STP)

Folder ini berisi seluruh data master, template impor, daftar akun pengguna, dan panduan operasional SIGAP E-Office untuk lingkungan **UPTD Kawasan Sains dan Teknologi Solo Technopark (STP)**.

---

## 📁 Daftar Berkas dalam Folder Ini:

1. **[PANDUAN_RINGKAS_PENGGUNA.md](./PANDUAN_RINGKAS_PENGGUNA.md)**
   * Panduan alur kerja inti bagi pegawai: Cara Login, Upload Surat Masuk oleh TU, Disposisi Pimpinan, Ruang Kerja Digital, dan Laporan Kinerja.

2. **[DAFTAR_AKUN_PEGAWAI_BLUD_STP.md](./DAFTAR_AKUN_PEGAWAI_BLUD_STP.md)**
   * Tabel daftar lengkap 45 akun pegawai BLUD STP Tahun 2026 beserta NIK, Password Default (`StpUser2026!`), dan jabatan.

3. **[jabatan_blud_stp.csv](./jabatan_blud_stp.csv)**
   * Template CSV Master Jabatan BLUD STP lengkap dengan relasi `namaAtasan` otomatis dan penanda `klasterStruktur` = `blud`.

4. **[users_blud_stp.csv](./users_blud_stp.csv)**
   * Template CSV Akun Pengguna BLUD STP yang siap diimpor massal ke menu Manajemen Pengguna.
