# Paket Dokumen & Data Master BLUD & ASN Solo Technopark (STP)

Folder ini berisi seluruh data master, template impor CSV, daftar akun pengguna, dan panduan operasional SIGAP E-Office untuk lingkungan **UPTD Kawasan Sains dan Teknologi Solo Technopark (STP)** (Klaster ASN & Klaster BLUD) dalam format **Markdown (.md)**, **PDF Siap Cetak (.pdf)**, dan **CSV (.csv)**.

---
