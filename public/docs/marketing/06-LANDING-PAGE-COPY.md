## FAQ SECTION

### Pertanyaan yang Sering Ditanyakan

**Q: Apakah perlu training lama untuk bisa menggunakan RUANG SIGAP?**
```
A: Tidak. Antarmuka RUANG SIGAP dirancang sesederhana WhatsApp, dengan semua teks
dalam Bahasa Indonesia. Kami menyediakan training 1-2 hari untuk semua pengguna,
dan pendampingan 30 hari pertama. Sebagian besar pengguna sudah mandiri dalam
minggu pertama.
```

**Q: Apakah data kami aman?**
```
A: Data setiap OPD sepenuhnya terisolasi — OPD lain tidak bisa mengakses data Anda.
Kami menggunakan infrastruktur Google Cloud dengan enkripsi end-to-end,
backup otomatis, dan standar keamanan enterprise. Lebih aman dari lemari arsip
fisik yang bisa terbakar atau terkena banjir.
```

**Q: Bagaimana jika koneksi internet terputus?**
```
A: RUANG SIGAP adalah Progressive Web App (PWA) dengan mode offline.
Anda masih bisa melihat data yang sudah dimuat, dan aksi yang dilakukan saat
offline akan otomatis tersinkronisasi saat koneksi kembali.
```

**Q: Berapa lama proses implementasinya?**
```
A: Untuk OPD standar: setup 1-2 hari, training 1-2 hari, sistem sudah aktif
dalam satu minggu. Kami handle semua konfigurasi teknis — Anda hanya perlu
menyiapkan data pengguna dan struktur jabatan.
```

**Q: Bisa terintegrasi dengan sistem yang sudah ada?**
```
A: RUANG SIGAP dapat berdampingan dengan sistem lain. Untuk integrasi spesifik
dengan sistem pemerintahan (SIASN, SIPD, dll.), tersedia untuk paket Enterprise.
Hubungi kami untuk diskusi teknis lebih lanjut.
```
