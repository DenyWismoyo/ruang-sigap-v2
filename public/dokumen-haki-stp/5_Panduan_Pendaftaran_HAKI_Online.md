# PANDUAN LANGKAH PENDAFTARAN HAKI (HAK CIPTA) ONLINE APLIKASI POROS

Berikut adalah panduan operasional praktis untuk mendaftarkan *Source Code* dan Aplikasi Poros ke DJKI Kemenkumham berdasarkan rujukan aturan untuk ASN:

## 1. Persiapan Dokumen
Sebelum membuka website, siapkan *file* berikut di komputer Anda:
1. **Scan KTP Anda** (format JPG/PDF).
2. **Surat Pernyataan Kepemilikan Karya** (Gunakan *file* nomor `2_Surat_Pernyataan_Kepemilikan_Karya.md` yang sudah ditandatangani di atas materai Rp10.000, lalu di-scan PDF).
3. **Contoh Source Code (Lampiran Ciptaan)**:
   - Ambil sekitar 15-20 halaman dari *source code* inti aplikasi Anda.
   - Disarankan mengambil dari *file-file* yang kompleks/unik (contoh: `Sidebar.tsx`, `layout.tsx`, logika API, atau skema Database/Prisma).
   - *Copy-paste* kode tersebut ke dalam dokumen MS Word, beri judul "Source Code Aplikasi Poros", simpan menjadi bentuk **PDF** (Maksimal ukuran file 20 MB).
4. **Manual Book** (Bisa gabungkan *file* `1_Manual_Book_Aplikasi_Poros.md` dan *screenshot* antarmuka aplikasi menjadi format PDF). 

## 2. Proses Pendaftaran di e-HakCipta
1. Buka situs resmi DJKI: **https://e-hakcipta.dgip.go.id/**
2. Buat akun baru (Register) dengan data pribadi Anda (Jangan gunakan data kantor OPD Anda). Verifikasi lewat email.
3. Login ke dalam portal. Di menu sebelah kiri, pilih **Hak Cipta > Permohonan Baru**.
4. **Detail Permohonan**:
   - *Jenis Permohonan*: UMUM / PERORANGAN
   - *Jenis Ciptaan*: PROGRAM KOMPUTER
   - *Sub Jenis Ciptaan*: Program Komputer
   - *Judul Ciptaan*: POROS
   - *Uraian Singkat Ciptaan*: (Isi deskripsi singkat aplikasi, lihat draf Surat Pernyataan).
   - *Tanggal dan Tempat Diumumkan Pertama Kali*: (Isi kapan aplikasi ini pertama kali Anda *deploy/publish*, misal: Surakarta, 1 Januari 2024).
5. **Data Pencipta**:
   - Masukkan data diri Anda (Nama, NIK, Alamat, Email).
6. **Data Pemegang Hak Cipta**:
   - Pilih "Sama dengan Pencipta" (Artinya Anda sebagai ASN adalah pemegang mutlaknya, bukan instansi Anda).
7. **Unggah Lampiran**:
   - Upload file *Scan* KTP.
   - Upload Surat Pernyataan Kepemilikan.
   - Upload Contoh *Source Code* & *Manual Book* di kolom Lampiran Ciptaan.
8. **Submit & Pembayaran**:
   - Setelah di-submit, Anda akan mendapatkan **Kode Billing (SIMPONI)**.
   - Biaya untuk pendaftaran perorangan / umum (Bukan UMKM) adalah sebesar **Rp 400.000**.
   - Lakukan pembayaran via Mobile Banking, Tokopedia, Kantor Pos, atau ATM menggunakan kode billing tersebut.

## 3. Penerbitan Sertifikat (Pencatatan Otomatis)
- Karena Program Komputer termasuk kategori **Pencatatan Otomatis (POP HC)**, apabila dokumen Anda lengkap dan pembayaran sudah tervalidasi, Sertifikat Hak Cipta akan otomatis terbit *dalam hitungan menit atau maksimal 1 hari kerja*.
- Sertifikat bisa langsung diunduh dalam bentuk PDF dan dicetak mandiri. Sertifikat inilah yang menjadi modal hukum utama Anda untuk membuat Perjanjian Lisensi dengan Solo Technopark.
